# 日语学习自动完成 FlowSpace 任务

第一版支持：日语端当天学习任务打卡完成后，自动完成 FlowSpace 同一学习日期的重复任务实例。包含手动打卡和现有完整听力训练的自动打卡；播放音频、访问页面和未完成练习不会触发。

## 启用服务

FlowSpace 使用当前 v2 工作区、control 凭据 keyring 和正常租户运行时。升级服务前使用现有运维命令分别执行 control 与 tenant 迁移，新增版本为 `0006_japanese_integration.sql` 和 `0017_japanese_integration.sql`。已经完成 v2 cutover 的工作区不重新执行 cutover，不开启 legacy writes。具体步骤沿用 [v2 发布手册](task-domain-v2-rollout-runbook.md)。

日语服务新增三个服务端环境变量，详见相邻仓库的 `docs/spec/flowspace-integration.md` 和 `.env.example`：

| 变量 | 用途 |
| --- | --- |
| `FLOWSPACE_BASE_URL` | FlowSpace 对外 HTTPS 根地址，允许已有部署前缀；本机测试允许 loopback HTTP |
| `FLOWSPACE_SOURCE_INSTANCE_ID` | 日语部署实例的固定身份，测试和生产使用不同值 |
| `FLOWSPACE_INTEGRATION_MASTER_KEY` | 32 字节加密主密钥的 64 位十六进制文本，保护连接凭据；通过私有环境配置保存 |

不要把主密钥加入版本库，修改主密钥前先处理已有加密连接；FlowSpace keyring 中仍被连接使用的旧 key 需要保留。使用当前源码重新构建和重启两个后端，日语管理端也使用正常构建流程。此功能不依赖消息中间件。

## 配对和关联

1. 以 FlowSpace 工作区 owner/admin 身份打开“用户设置 → 日语联动”，生成配对码。
2. 登录日语项目，打开“设置 → FlowSpace 联动”，粘贴配对码连接。配对码有效期 10 分钟，成功后不可重用；若配对结果丢失，生成新码，并在 FlowSpace 停用未使用的旧连接。
3. 返回 FlowSpace 刷新状态，选择具体账号、计划、时段和学习任务，以及已有的同一时区的重复任务。任务定义中也有“设置日语任务自动完成”入口。
4. 核对来源和目标，保存关联。首次关联默认从当天生效；修改既有关联默认从次日生效，历史消息保留原路由。界面显示具体生效日期。
5. 在日语端完成学习任务。FlowSpace 在后台接收和处理；设置页区分“已送达，等待处理”和“已同步完成”。网页刷新或再次进入任务页后可见更新，iPhone 在下次成功 mobile-v2 同步后取得同一状态。

两个项目账号独立，不需要相同用户名或 ID。配对凭据只保存在两个后端，网页不会取得签名密钥。当前界面不代替日语项目登录，也不共享浏览器会话。

## 完成与异常处理

- 今天完成只影响今天对应的执行实例，整个重复任务继续存在。跨日补发使用原学习日期。
- 重复事件与丢失回执后的重传不会重复完成或生成多条执行日志。
- 日语端撤销打卡后，不自动重新打开已经完成的 FlowSpace 实例；同步记录保留来源撤销信息。
- FlowSpace 中手动重新打开后，同一来源版本不会再次自动完成；新的未完成→完成转换可以再次同步。
- 被阻塞、跳过、取消、暂停、归档、删除的目标及未满足的完成条件不会被强制覆盖。修复完成条件等可恢复原因后，对原关联的失败记录点击“重试处理”。
- 计划或重复规则变化会使原关联等待人工检查；保存新关联使用新的生效版本，不把历史消息改发给新目标。
- 没有关联时收到的历史事件不自动套用后来创建的关联。首版暂不提供历史重新映射、批量导入计划、整时段聚合或跨项目撤销回写。
- “从明日起暂停关联”保留当天映射；要立即禁止整个连接继续写入，使用 FlowSpace 的“停用连接”。停用会释放原任务的关联占用，可重新配对并关联。
- 日语端断开会停止本地后续投递；如需撤销远端凭据及尚未处理的接收消息，也在 FlowSpace 停用连接。

开始学习仍通过日语项目已有入口或任务中自行添加的附件链接访问；本版未新增跨应用单点登录或自动推导生产网址。

## 验证

前端执行 `frontend/` 下的 `npm run test:regression`。跨项目 PostgreSQL + HTTP 回归及其验证边界见 [联动测试说明](japanese-learning-integration-testing.md)。本功能测试使用隔离数据库和临时工作区，不代表已部署或连接现有线上账号。
