# 网页语音输入与计划生成

## 使用流程

在工作台点击“语音计划”，或在“快速捕获”中切换“生成计划”。项目详情也提供同一入口，并自动带入项目。桌面浏览器使用对话框，手机网页使用全屏面板。

1. 输入文字，或点击“开始录音”，说完后结束。每段录音最多 3 分钟、20 MiB。
2. 上传并转写后核对文字。可以回听录音，纠正日期、时间和专有名词。
3. 点击生成草稿，核对任务、项目、日期、时段和重复规则。用户修订的文字作为生成输入，原始转写保留。
4. 编辑任务，取消勾选不想创建的项，检查安排。时间重叠作为有限窗口内的提示，需要用户明确选择是否保留。
5. 选择“创建并开始执行”或保存为任务草稿，确认后整批创建。规划中的项目在用户选择开始执行时会被启用。

原始口述保存为该功能自己的草稿，不自动创建笔记。文字编辑自动保存，重新打开入口可继续最近未完成草稿。尚未上传的录音仍在当前页面，关闭或刷新前应先上传；关闭时会提示未保存内容。

一次草稿只提交一次。未勾选任务本次不创建，需要继续时复制为新草稿。成功后可直接查看项目、创建的任务和日历。首次生成、转写失败都可以重试；修改输入后，旧作业结果不会覆盖新的文字。

## 复用现有服务配置

进入“用户设置 → AI 服务”：

- **语音转写**：使用该工作区已有的转写服务绑定。支持现有 FunASR、SenseVoice、Faster Whisper（Wyoming）及 OpenAI 兼容服务。
- **文本 AI**：使用已有文本服务生成结构化计划。计划生成与语音识别分别使用各自配置。
- **对象存储**：使用工作区已有的 MinIO/S3 绑定保存私有录音。

服务没有配置或被关闭时，面板显示不可用原因。语音不可用时仍可使用文字输入；文本服务不可用时可以保留草稿，完成配置后再生成。

识别失败不会自动改用另一家外部服务。语音、文本服务的凭据由后端管理，网页只访问 FlowSpace API。内网服务地址与允许的 CIDR 沿用现有运行时设置，详见[用户设置指南](user-settings.md)。

## 录音兼容性与部署

网页通过 `getUserMedia` / `MediaRecorder` 录制，并按浏览器支持的 MIME 选择格式。Chrome 的 WebM/Opus 与 Safari 的 MP4/AAC 在后端归一化成 16 kHz、单声道 PCM WAV，然后交给现有转写适配器。

- 后端运行环境需要 `ffmpeg`。现有 backend Docker 镜像已经包含该工具；本机直接运行二进制时也需安装，并确保它位于 PATH。
- 麦克风需要 HTTPS 或浏览器允许的本机 loopback 安全上下文。手机通过局域网 HTTP IP 打开的页面不适合作为录音验收入口。
- 真实时长和大小在服务端再次校验。超长、空内容、损坏或 MIME 不符的录音会失败，用户可重录或使用文字。
- 原始音频仅在草稿校对期间使用。提交、删除草稿后由后台清理；未完成草稿的录音保留 7 天。文字和计划可继续保留。

### 数据库迁移

该功能增加控制库 `0005_plan_generation_feature.sql` 和租户库 `0016_web_planning.sql`。升级按项目现有管理流程，显式执行控制库和对应租户数据库迁移，再运行新二进制。请求处理和作业领取不会自动执行 DDL。

在按 AGENTS.md 设置了正确的控制库与租户库环境后，从 backend 执行：

```sh
go run ./cmd/flowspace-admin migrate-control
go run ./cmd/flowspace-admin migrate-tenant
```

迁移为已有工作区补充独立的 `plan_generation` 功能设置，并保持原有文本/语音服务绑定。功能仍取决于工作区可用的文本 AI 配置。此迁移不执行任务领域 cutover，也不打开 legacy writes。

本地测试继续使用 AGENTS.md 指定的 v2 双 SQLite 数据库及 4100/4101 端口。标准测试库或既有 cutover 状态缺失时先恢复环境，不能通过另建 v1 运行环境代替。

## 当前边界

- 第一版为录完后转写，不提供实时逐字字幕或词级置信度。
- 支持已有 v2 的单次、日/周/月重复安排；缺具体时间的描述保留为待安排任务，并展示需要补充的信息。
- 重复任务创建一个任务定义，由既有执行生成器产生后续执行。
- 冲突提示检查未来 14 天内的已物化安排，提交前再次检查；不保证无限未来或并发外部编辑绝无重叠。
- 第一版用于新增计划，修改已有任务、批量重排、覆盖路线图不在本次功能内。

详细交互、事务和接口设计见[设计方案](superpowers/specs/2026-11-19-web-voice-plan-design.md)。
