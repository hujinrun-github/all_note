# FlowSpace macOS 原生应用设计方案

日期：2026-08-08  
状态：产品边界已确认，视觉方案已按 macOS 26 更新，Web v2 基线已核对

详细页面状态、快捷键、冲突、离线和窗口行为见 [FlowSpace macOS 26 详细交互规格](./2026-08-08-flowspace-macos-interaction-spec.md)。

## 1. 结论

推荐做成“原生 SwiftUI 外壳 + 两个局部 Web 能力”的 macOS 应用，而不是把现有站点整体塞进 `WKWebView`。

- 导航、任务列表、项目、日历、检查器、设置、菜单和窗口全部使用 SwiftUI。
- 继续使用现有 Go 后端与 v2 task-domain API，后端仍是权威数据源。
- 只有富文本编辑器和思维导图画布在第一阶段复用现有 Tiptap / Canvas 实现，通过受限的 `WKWebView` bridge 嵌入。
- 后续再按投入产出决定是否把编辑器或脑图完全原生化。

这样能保留 FlowSpace 现有业务能力，同时获得真正的 macOS 交互：菜单栏、快捷键、多窗口、原生侧边栏、检查器、拖放和状态恢复。

本文使用以下能力标签，避免把 Web 现状、桌面优化和未来后端能力混为一谈：

- `【Web 对齐】`：2026-08-08 的 v2 Web 正式页面已经具备，macOS 首版必须覆盖。
- `【macOS 增强】`：不属于当前 Web 等价基线，但可利用现有 API 提供更合适的桌面交互。
- `【后端依赖】`：当前 Web 或 API 尚不具备完整数据契约，完成后端设计前不得作为首版已承诺能力。

“覆盖现有 Web 全部功能”只指 `【Web 对齐】` 项，不表示所有 `【macOS 增强】` 都已经存在于 Web，也不表示 `【后端依赖】` 自动进入首版范围。

## 2. 已确认的产品边界

以下决定已确认：

1. 只支持 macOS 26，不为旧系统保留兼容分支。
2. 接受混合实现：外层与常规页面使用原生 SwiftUI，富文本编辑器和思维导图局部使用 `WKWebView`。
3. 首个正式版本覆盖本文列出的全部 `【Web 对齐】` 功能，不削减账号管理、运行时设置、同步、Roadmap、脑图和内容导入。
4. App 连接用户配置的现有 FlowSpace 服务，不在 Mac 上自动启动或管理后端。
5. 只支持已完成 v2 cutover 的工作空间，不提供 v1 页面或数据回退。
6. 离线写入、持久化离线草稿与完整本地数据库不是首版目标；首版只提供最近内容缓存和断网只读。网络中断前尚未保存的编辑内容只能保留在当前窗口内存中，并提供复制或放弃，不进入后台待提交队列。

### 3.2 场景与窗口

| 场景 | SwiftUI 类型 | 用途 |
|---|---|---|
| 主工作区 | `WindowGroup("FlowSpace", id: "workspace")` | 今日、任务、项目、日历、笔记和复盘；保留尺寸、位置和选择状态 |
| 笔记窗口 | `WindowGroup(for: Note.ID.self)` | 双击笔记或“在新窗口打开”，支持同时编辑多篇笔记 |
| 快速捕获 | 单例 `Window`，必要时窄桥接 `NSPanel` | `【Web 对齐】` 创建任务；`【macOS 增强】` 直接创建笔记或日程 |
| 学习脑图 | `WindowGroup(for: RoadmapNode.ID.self)` | 大画布、独立缩放和全屏，不挤占主工作区 |
| 导入任务 | 单例 `Window` | `【macOS 增强】` 把 Web tray 的播客进度、错误和重试移入独立 Import Activity |
| 设置 | `Settings` | 个人资料、安全、数据库、对象存储、AI 和同步 |
| 账号管理 | 单例 `Window` | 仅管理员可见，不放普通用户主导航 |

主窗口启用系统状态恢复；快速捕获、导入任务、设置和账号管理不恢复为启动窗口。

### 3.3 状态归属

- `AppSession`：登录用户、工作空间、capabilities 和 API 会话，全 App 共享。
- `WorkspaceStore`：跨窗口共享的业务缓存和失效通知。
- `@SceneStorage`：每个窗口的当前模块、选中任务、侧边栏/检查器展开状态、日历日期和滚动位置。
- `@AppStorage`：外观、默认捕获类型、默认日历视图等用户偏好。
- 任务、项目与笔记的草稿留在创建它的窗口中，不放入单一全局状态。

### 3.4 API 与认证

- 登录使用现有会话 Cookie；GitHub OAuth 通过 `ASWebAuthenticationSession` 完成回调，并使用服务端短时一次性 code 与 PKCE verifier 兑换 Cookie。自定义 URL Scheme 不携带会话令牌。首次启动先输入服务地址，验证健康状态后再进入登录。
- 登录后首先请求 `/api/task-domain/capabilities`，只有 `model_version=v2` 且 `available=true` 才进入工作区。
- 任务、项目、日历和 Roadmap 使用现有 task-domain v2 接口；笔记、搜索、同步和运行时设置继续使用各自现有 API。
- task-domain v2、Roadmap 与运行时 binding mutation 保留现有 revision / CAS 语义。遇到冲突时刷新当前对象并展示可获得的远端 revision，不静默覆盖。
- 笔记接口当前没有 revision / CAS；首版沿用 Web 的保存与错误提示。文稿版本比较属于 `【后端依赖】`，不能仅由客户端模拟。
- `URLSession` actor 统一处理 Cookie、401 重新认证、重试、取消和结构化错误。

### 3.5 Web v2 功能基线

| 模块 | 2026-08-08 Web 基线 | macOS 首版边界 |
|---|---|---|
| 登录与工作空间 | 邮箱密码、GitHub OAuth、强制改密、capability gate | `【Web 对齐】`；额外增加服务地址连接页属于 `【macOS 增强】` |
| 今日 | 今天/本周/本月/已逾期/已完成；本周和本月按 task definition 折叠 occurrence | `【Web 对齐】` |
| 任务 | 固定视图、项目/优先级/状态/日期筛选、occurrence/task definition inspector、生命周期命令 | `【Web 对齐】`；批量、多选、右键和高密度键盘流属于 `【macOS 增强】` |
| 未整理 | inbox occurrence 列表、归入项目、满足门槛后直接完成 | `【Web 对齐】`；连续编辑标题/优先级/安排属于 `【macOS 增强】` |
| 项目 | 项目列表与详情、六个详情分区、任务迁移/取消后完成项目 | `【Web 对齐】`；项目列表搜索和同页 detail column 属于 `【macOS 增强】` |
| Roadmap / 脑图 | 阶段 rail、阶段工作区、ledger、节点任务脑图、任务编辑与执行 | `【Web 对齐】`；节点批量重排与画布布局持久化属于 `【后端依赖】` |

| 笔记 | 三栏笔记库、Tiptap、假名、任务关联、附件、Notion/Obsidian 同步 | `【Web 对齐】`；多窗口和系统 Find 属于 `【macOS 增强】`，文稿 revision conflict 属于 `【后端依赖】` |
| 搜索 | 任务/项目/日程/笔记分类、最近搜索 | `【Web 对齐】`；命令结果和跨窗口打开属于 `【macOS 增强】` |
| 每日总结 | 本周/本月、完成记录、待关注事项、最近笔记 | `【Web 对齐】`；日范围和专注时间分别属于 `【macOS 增强】`、`【后端依赖】` |
| 快速捕获 | 创建任务，可选择项目、日期、时间块和重复 | `【Web 对齐】`；直接创建笔记或日程属于 `【macOS 增强】` |
| 内容导入 | Notes 中发起播客导入，以 tray 查看阶段、错误、重试和生成笔记 | `【Web 对齐】`；独立 Import Activity 窗口属于 `【macOS 增强】` |
| 设置与管理 | 个人资料、安全、数据库、对象存储、AI、同步设置、管理员账号管理 | `【Web 对齐】`；通用、连接和通知为 macOS 专属设置 |

## 4. 信息架构

### 4.1 主侧边栏

主侧边栏保持轻量、原生 source-list 风格，每行最多一个图标、一行标题和一个可选计数：

```text
聚焦
  今日
  任务
  未整理            3

计划
  项目
  日历

知识
  笔记

回顾
  每日总结
```

搜索不再占用固定导航项，统一为工具栏搜索与 `⌘K` 命令面板。设置进入标准 App 菜单。管理员登录时，账号管理出现在“窗口”或 FlowSpace 菜单中。导入任务不占固定导航项，通过 Notes、File → Import 或 Window → Import Activity 进入。

当选中“笔记”时，侧边栏下半部展开项目、未归属和常用标签；当选中“项目”时，可展开固定/最近项目。这样避免 Web 版全局侧栏之外再叠一层过滤侧栏。

### 4.2 工具栏

- 左侧：系统侧边栏按钮、返回/前进（存在导航历史时）。
- 中间：当前页面标题或当前项目/笔记标题。
- 右侧：搜索、筛选、检查器、新建/快速捕获、账号头像。
- 关键动作同时出现在菜单和快捷键中，不只依赖工具栏图标。

## 5. 页面设计

### 5.1 今日

布局：任务列表 + 可收起检查器。

- 顶部范围：今天、本周、本月、已逾期、已完成。
- 列表分为“时间块”和“灵活安排”，本周/本月按任务折叠执行实例。
- `【Web 对齐】` 行内完成；开始、阻塞、解除阻塞和重新打开通过检查器完成。macOS 可把常用命令补充到 contextual menu。
- 选中一行后打开右侧检查器，显示任务定义、所属项目、安排、要求和执行历史。
- `【macOS 增强】` 空白处双击或 `N` 创建任务；`⌘⇧N` 打开快速捕获。

### 5.2 任务

布局：视图侧栏/筛选条 + 表格式任务列表 + 检查器。

- 固定视图：收件箱、今天、接下来、已逾期、无日期、重复、已完成、草稿。
- `【Web 对齐】` 项目、优先级、状态、日期范围放在筛选条中。
- `【macOS 增强】` 已启用筛选以 token 显示并可一键清除；列表支持键盘上下选择和 Space 完成。
- `【macOS 增强】` 批量模式只在用户主动开启后出现，避免持续占用主界面；它不是当前 Web 已完成能力。
- 右侧检查器区分“执行实例”和“任务定义”，沿用现有 v2 语义。

### 5.3 未整理

布局：收件箱列表 + 整理检查器。

- 左侧只展示尚未归入明确项目的捕获项。
- `【Web 对齐】` 右侧先覆盖项目归属和直接完成。
- `【macOS 增强】` 再扩展为可编辑标题、优先级、安排和重复规则的连续表单，并提供 `⌘↩` 保存下一条与 `⌘⌫` 删除。

### 5.4 项目列表

布局：原生 `Table` 优先，紧凑窗口降级为 `List`。

- 列：名称、类型、周期、状态、进度、下一次行动。
- 顶部只保留类型、周期、状态筛选和新建项目。
- 双击在当前窗口进入项目；Option-双击在新窗口打开。
- 新建与编辑使用 sheet，不在列表中展开大表单。

### 5.5 项目详情

布局：项目标题与进度 + 内容区 + 可选任务检查器。

- 分区：概览、任务、日程、笔记、学习路线（仅学习项目）、历史。
- 概览使用少量真实摘要：进度、下一次行动、近期日程和最近笔记，不制造无业务含义的仪表盘卡片。
- “学习路线”在主窗口中展示阶段 rail、阶段工作区和进度 ledger。
- 点击 Roadmap 节点进入独立脑图窗口，保留原节点选择、缩放和画布位置。

### 5.6 日历

布局：周/月/年视图 + 事件检查器。

- 默认周视图；工具栏提供上一周期、今天、下一周期、视图切换和时区。
- `【Web 对齐】` 全天区固定在顶部；单击空白时间槽即以对应日期和时间作为可编辑默认值打开创建 sheet，不把时间写死。
- `【Web 对齐】` 单击事件选中并打开检查器，通过字段编辑日期、开始时间和时长。
- `【macOS 增强】` 时间块可精确拖放改期，后续再增加拖拽边缘修改时长；这两项不作为 Web 等价验收依据。
- 重复任务改期时使用明确的 sheet 询问“仅本次”或“本次及以后”。

### 5.7 笔记库

布局：主侧边栏上下文过滤 + 笔记列表 + 预览。

- 项目、未归属和标签进入主侧边栏的上下文区域，取消 Web 版额外过滤卡片列。
- 中列显示标题、两行摘要、项目/标签和更新时间，支持最近更新/标题排序。
- 右侧显示只读预览；双击或 `⌘O` 在独立笔记窗口打开。
- 新建笔记使用 `⌘N`，播客导入和同步入口放在 File/Import 与工具栏更多菜单。

### 5.8 笔记编辑器

布局：居中的文稿 + 原生检查器。

- 正文宽度约 720–760 pt，标题和正文保持当前编辑型排版。
- 第一阶段把 Tiptap 作为本地打包的 Web 内容嵌入，只传递 note ID、Markdown、选择和保存事件，不加载整个 Web App。
- 原生检查器管理项目、关联任务、同步目标、附件和字数。
- `【Web 对齐】` 支持手动保存、5 秒自动保存状态、项目/任务关联、附件和同步。
- `【macOS 增强】` 支持独立多窗口、系统 Find 和拖入附件。
- `【后端依赖】` 文稿版本冲突比较需要笔记 revision / CAS，后端契约完成前不承诺。
- 日文假名、Markdown、气泡格式菜单沿用现有能力。

### 5.9 全局搜索

- `【Web 对齐】` 完整搜索覆盖任务、项目、日程和笔记，提供结果类型过滤和最近搜索。
- `【macOS 增强】` `⌘K` 打开命令面板并增加应用命令；`⌘⇧F` 打开独立完整搜索窗口。
- 在编辑器内，`⌘F` 只搜索当前笔记。

### 5.10 每日总结

- `【Web 对齐】` 顶部切换本周/本月。
- `【macOS 增强】` 可增加日范围和日期选择。
- 主区展示完成记录与完成率；右侧展示仍需关注的事项和最近知识产出。
- 复盘内容保持可行动：点击任务或笔记直接打开对应对象。
- `【后端依赖】` 专注时间需要明确的数据来源与统计接口，不在现有 Web 对齐范围。

### 5.11 设置

使用独立 `Settings` scene，两份规格统一为以下八类：

1. `【macOS 增强】` 通用：启动页、菜单栏、提示音和默认日历视图。
2. `【macOS 增强】` 连接：服务地址、测试连接和切换服务。
3. `【Web 对齐】` 个人资料：头像、显示名、语言和时区。
4. `【Web 对齐】` 账号安全：密码；登录会话管理属于后续扩展。
5. `【Web 对齐】` 同步：Notion、Obsidian 和笔记绑定默认行为。
6. `【Web 对齐】` 存储：数据库、对象存储和 binding 状态，只对有权限用户开放。
7. `【Web 对齐】` AI 服务：文本、转写和 Codex 订阅配置。
8. `【macOS 增强】` 通知：任务、导入和同步通知。

## 6. macOS 交互约定

| 快速捕获 | `⌘⇧N` |

| 显示/隐藏检查器 | `⌘⌥I` |

## 7. macOS 26 Liquid Glass 视觉方向

- 使用 macOS 26 原生 `NavigationSplitView`、浮动 toolbar、`searchable`、inspector 和标准 sheet，让系统自动提供 Liquid Glass 与 scroll-edge 效果。
- 侧边栏保持通透的系统 source-list 材质，导航行只在选中或 hover 时浮现玻璃高亮，不给每个入口增加卡片或彩色底板。
- Toolbar 按功能分组；搜索、检查器、快速捕获分别位于清晰的玻璃组中。头像通过 `sharedBackgroundVisibility` 保持独立。
- FlowSpace 蓝色只用于主要动作、当前选择和进度；普通图标保持单色，状态色只表达完成、阻塞、错误等语义。
- 内容区使用安静的实体阅读面，与周围玻璃 chrome 形成层次；列表依靠间距、细分隔线与选择态，不堆叠网页式大卡片。
- 自定义快速捕获、搜索命令面板和浮动脑图控件使用同一 `GlassEffectContainer`；交互控件启用 interactive glass，不手写多套模糊背景。
- Sheet 使用系统材质和同心圆角，不额外覆盖暗色 scrim 或自定义 frosted background。
- 完整支持 Light/Dark、Increase Contrast、Reduce Transparency 和辅助字号。
- 最小主窗口建议 920 × 620 pt，默认 1240 × 780 pt；检查器在窄窗口自动收起。
