# FlowSpace macOS 26 详细交互规格

日期：2026-08-08  
状态：可进入工程设计与拆分，Web v2 基线已核对  
依赖：[FlowSpace macOS 原生应用设计方案](./2026-08-08-flowspace-macos-app-design.md)

## 1. 交互目标

FlowSpace macOS 版覆盖现有 Web 的 `【Web 对齐】` 功能，但不逐页照搬 Web 布局。`【macOS 增强】` 表示使用现有 API 增加的桌面效率能力；`【后端依赖】` 表示当前 API 尚不能完整支持，不纳入首版 Web 等价验收。能力标签与基线矩阵以总体设计方案的 3.5 节为准。

所有功能统一到以下桌面交互模型：

1. 主侧边栏选择工作域。
2. 中央内容区浏览和操作对象。
3. 右侧检查器处理当前选择的属性与次要命令。
4. Sheet 只承载创建、危险确认和必须中断当前流程的决定。
5. 笔记、脑图等并行内容允许独立窗口。
6. 菜单、快捷键、右键菜单与拖放提供桌面效率，但关键动作始终保留可见入口。

## 2. 全局状态与选择模型

### 2.1 App 级状态

`AppSession` 持有：

- 当前服务地址与连接状态；
- 登录用户、角色与工作空间；
- task-domain capabilities；
- Cookie 会话和 OAuth 状态；
- 服务端时间偏移、网络状态和重新认证状态。

`WorkspaceStore` 持有跨窗口共享的规范化数据缓存和 mutation 失效通知。窗口不直接共享选择、筛选、草稿或滚动位置。

### 2.2 Window/Scene 级状态

每个主工作区窗口独立保存：

- 当前侧边栏目的地；
- 当前任务、项目、日程或笔记选择；
- 当前分段视图与筛选条件；
- 侧边栏、检查器的显示状态和宽度；
- 日历 anchor date、视图和时区；
- 项目详情当前 section；
- 滚动位置与展开节点。

选择状态优先使用稳定 ID。刷新数据后若对象仍存在则保留选择；对象被删除、归档或不再匹配筛选时，选择移动到相邻对象，列表为空时关闭检查器。

### 2.3 View 级状态

创建表单、重排草稿、临时搜索词、弹出菜单和 hover 反馈只属于当前 View。关闭 sheet 时未提交草稿默认丢弃；已经输入内容时需提示“丢弃更改”。

## 3. 启动、服务连接与登录

### 3.1 首次启动

主窗口显示连接页：

1. 输入 FlowSpace 服务地址。
2. 客户端规范化 URL，仅允许 `http` 或 `https`。
3. 点击“测试连接”，请求健康接口并显示服务版本。
4. 测试通过后保存为当前连接，并进入登录。
5. `http` 非本机连接显示常驻安全提醒，但允许用户确认后继续；不静默升级或改写地址。

连接失败时区分 DNS、连接拒绝、超时、TLS、服务版本不兼容和返回内容异常。错误信息保留用户输入，不清空表单。

### 3.2 登录

- 邮箱密码登录在当前窗口完成。
- GitHub 登录使用 `ASWebAuthenticationSession`；自定义 URL Scheme 只接收短时一次性 code，客户端用 PKCE verifier 向当前服务兑换 Cookie，不在 URL 中传递会话令牌；取消后回到登录页，不产生错误 toast。
- 登录成功后请求用户资料和 `/api/task-domain/capabilities`。
- `model_version` 不是 v2 或 `available=false` 时进入只读诊断页，不展示任何 v1 工作区。
- 用户被要求修改密码时先打开安全设置 sheet，成功后再进入主工作区。

### 3.3 后续启动

- 优先恢复上次服务连接和 Cookie 会话。
- 会话有效时直接进入恢复的窗口状态。
- 401 时统一清理内存数据，保留服务地址，并返回登录。
- 服务离线但存在缓存时进入只读模式，窗口标题下显示“离线 · 上次同步时间”。首版不建立持久化待提交队列，也不把内存中的未保存内容描述成已经安全保存的“离线草稿”。

## 4. Scene 与窗口生命周期

| 场景 | 生命周期 | 恢复策略 | 默认尺寸 |
|---|---|---|---|
| 主工作区 `WindowGroup` | 可多窗口 | 恢复尺寸、位置、目的地和选择 | 1240 × 780 pt |
| 笔记窗口 `WindowGroup(for:)` | 每篇笔记可多开 | 恢复打开的文稿和位置 | 980 × 760 pt |
| 脑图窗口 `WindowGroup(for:)` | 每个 Roadmap 节点一窗 | 恢复缩放、平移和选择 | 1180 × 780 pt |
| 快速捕获 `Window` | 单例 | 不恢复 | 520 × 260 pt |
| 内容导入 `Window` | 单例 | 不在启动时自动恢复 | 760 × 560 pt |
| 账号管理 `Window` | 单例、管理员 | 不恢复 | 820 × 620 pt |
| 设置 `Settings` | 系统单例 | 交给系统 | 720 × 540 pt |

主工作区保留 Dock 应用行为。菜单栏入口是可选辅助能力，不把 App 改成 accessory-only。

## 5. 主窗口与工具栏

### 5.1 主侧边栏

固定顺序：

- 聚焦：今日、任务、未整理；
- 计划：项目、日历；
- 知识：笔记；
- 回顾：每日总结。

侧边栏底部显示用户头像、在线/离线状态。点击头像打开菜单：个人资料、设置、账号管理（管理员）、退出登录。

导入任务不占固定导航项。用户从 Notes toolbar、File → Import 发起导入，从 Window → Import Activity 打开任务窗口；活跃任务数可显示在对应菜单项上。

侧边栏行为：

- 单击切换目的地，并恢复该目的地在当前窗口中的选择和筛选。
- `⌘⌃S` 显示/隐藏侧边栏。
- 计数仅用于未整理、活跃导入或用户必须处理的状态；普通模块不显示装饰性数字。
- 窄窗口自动隐藏检查器，极窄窗口只显示侧边栏图标。

### 5.2 Toolbar

全局 trailing toolbar 分为三组：

1. 搜索：`⌘K`；
2. 检查器：`⌘⌥I`，仅当前页面支持选择时启用；
3. 快速捕获：`⌘⇧N`。

页面局部动作位于内容标题区或独立 toolbar group，例如“新建日程”“批量选择”“打开脑图”。不要把所有页面动作堆到全局 toolbar。

### 5.3 Inspector

- 选择对象后自动打开仅发生在用户首次进入该模块时；之后尊重用户的显示偏好。
- 列表选择变化只替换 inspector 内容，不重建主布局。
- Inspector 宽度 260–340 pt，可拖动调整。
- `Esc` 先关闭 popover/sheet，再取消列表选择，最后才关闭非主窗口。

## 6. 今日

### 6.1 结构

- `【Web 对齐】` Header：日期、待完成数和逾期数；问候属于可选文案。
- `【后端依赖】` 专注时间在统计口径和接口确定前不展示。
- 范围：今天、本周、本月、已逾期、已完成。
- 列表：时间块、灵活安排；本周/本月按任务定义折叠执行实例。
- Inspector：当前 occurrence 与对应 task definition 摘要。

### 6.2 行为

- 单击行：选择并更新 inspector。
- `【Web 对齐】` 单击圆形完成按钮立即发送完成命令，行进入 pending，成功后移动到已完成；重新打开通过 inspector 的明确入口完成。
- `【macOS 增强】` 完成成功后可提供 8 秒“重新打开”，它使用服务端返回的新 revision 发送 occurrence reopen，不缓存或重放旧请求。
- `【macOS 增强】` Space 完成/重新打开所选执行实例；Return 进入标题行内编辑，再次 Return 保存，Esc 取消。
- `【macOS 增强】` `⌘↩` 开始任务。首版不增加停止计时或计时领域。
- `【macOS 增强】` 拖到日期范围或日历时只打开改期预览，确认后才提交。
- 选中重复实例改期时必须询问“仅本次”或“本次及以后”。

### 6.3 状态

- 今日无任务：显示“今天已经清空”，保留创建任务和查看本周入口。
- 逾期项不使用整行红色，只在日期和状态上表达警告。
- Revision conflict：撤销本地 pending 样式，刷新对象，在 inspector 顶部展示差异条。

## 7. 任务

### 7.1 视图

固定视图为任务收件箱、今天、接下来、已逾期、无日期、重复、已完成、草稿。默认打开“接下来”。每个视图保留独立滚动位置。

`【Web 对齐】` 筛选器包括项目、优先级、执行状态和日期范围。`【macOS 增强】` 启用后以可移除 token 表示；`⌘⌥R` 清空当前模块筛选。

### 7.2 列表与选择

- 列为完成、标题/项目、安排、执行状态。
- `【macOS 增强】` ↑/↓ 移动选择，Shift 扩展多选，`⌘A` 只选择当前过滤结果。
- `【macOS 增强】` 双击在当前窗口打开完整任务编辑 sheet；Option-双击在新工作区窗口打开并定位该任务。
- `【macOS 增强】` 右键菜单：开始、阻塞/解除阻塞、改期、复制链接、移动项目、取消、归档。

### 7.3 批量模式

`【macOS 增强】` 当前 Web 的“批量选择”尚未形成可用流程。macOS 批量工具栏仅在选择两个及以上对象时出现，允许完成、移动项目、设置优先级、改期和取消；删除不提供批量入口。首版采用逐对象 CAS 命令并展示成功/失败明细，不把部分成功显示成全部成功；跨重复任务的改期先按 task definition 分组确认。

### 7.4 Draft 与定义

草稿视图展示 task definition，不伪装成 occurrence。Inspector 命令为发布、编辑、取消或删除草稿；发布后生成执行实例并移动到对应日期视图。

## 8. 未整理

- 列表只显示系统 inbox 项目中的未整理执行实例。
- `【Web 对齐】` Inspector 提供目标项目和直接完成；项目加载失败时禁止保存。
- `【macOS 增强】` 连续表单再增加标题、优先级、安排、时间块和重复规则。
- `【macOS 增强】` `⌘↩` 保存并选择下一条；`⌘⌫` 删除，需要一次确认，确认 sheet 默认聚焦“取消”。
- 成功整理后当前项淡出，下一项保持相同字段焦点，便于键盘连续处理。
- 项目列表加载失败时禁止保存，不允许把用户选择悄悄回退到系统 inbox。

## 9. 项目列表

- 左侧 supplementary column 显示项目搜索和项目列表；右侧直接显示所选项目详情。
- 行展示名称、类型、状态和进度，不在侧边栏堆叠完整元数据。
- `⌘N` 在此模块创建项目；sheet 包含名称、标准/学习、短期/长期和初始状态。
- 删除项目始终展示影响：任务定义数、未完成实例数、笔记关联数和 Roadmap 状态。
- 不能直接删除仍有受保护执行记录的项目；界面给出迁移、完成或取消路径。

## 10. 项目详情

### 10.1 Section

概览、任务、日程、笔记、学习路线（学习项目）、历史。切换 section 不改变项目选择。

### 10.2 概览

只展示可行动内容：总体进度、下一次行动、近期日程、最近笔记、阻塞事项。点击摘要直接切到对应 section 并选择对象。

### 10.3 项目生命周期

- planning：主要动作“开始项目”；
- active：允许完成、暂停或编辑；
- completed：默认只读；`【macOS 增强】` 可调用现有 project restore 命令明确选择恢复状态；
- archived：从普通列表隐藏；`【macOS 增强】` 在归档视图调用 project restore；
- 系统项目隐藏不适用的生命周期命令。

完成仍有未结束任务的项目时，sheet 明确提供迁移、取消或返回处理，不自动丢弃执行记录。

## 11. 学习 Roadmap

- 阶段 rail 表达顺序和进度；中央区域展示所选阶段任务；右侧 ledger 展示完成、阻塞和未整理统计。
- 单击阶段保持同窗切换；双击或点击“打开脑图”进入独立脑图窗口。
- 生成或重新生成 Roadmap 使用 sheet；提交后关闭 sheet，在页面内展示生成进度。
- 已关联任务阻止替换节点时，错误说明受保护节点并提供“查看关联任务”。
- `【后端依赖】` 节点原子重排需要批量顺序 mutation。接口完成前只允许新增到末尾和逐节点编辑，不展示“保存重排”或冲突比较。

## 12. 节点脑图

- 独立窗口使用大画布；toolbar 提供新增任务、筛选、缩放、适应画布和 inspector。
- `【Web 对齐】` 单击节点选择、编辑标题、添加任务、修改安排与执行状态；拖动空白平移并支持画布缩放。
- `【macOS 增强】` 双击标题编辑和节点自由拖动可保留在当前窗口会话内。
- Return 新建同级任务，Tab 新建子任务，Delete 发起取消/删除判断。
- `【macOS 增强】` 右键菜单：新增同级任务、重命名、打开任务详情和取消。移动到其他 Roadmap 节点只有在 task update 合同和受保护记录规则验证后再加入。
- Mini-map 仅在节点超出可见区域时出现。
- `【后端依赖】` 画布布局持久化需要独立布局模型和 revision。在该接口完成前，节点位置只属于窗口状态，不显示“已保存布局”。
- `⌘0` 适应画布，`⌘+` / `⌘-` 缩放。

## 13. 日历

### 13.1 视图

周、月、年；默认周视图。Toolbar 提供上一周期、今天、下一周期、时区和新建日程。

### 13.2 创建与选择

- `【Web 对齐】` 单击时间槽：用该日期和时间作为可编辑默认值打开创建 sheet；用户可以修改日期、开始时间和结束时间。
- `【Web 对齐】` 单击全天区的新增入口：创建 date/all-day 安排。
- 单击事件：选择并打开 inspector。
- `【macOS 增强】` Return 打开编辑；Space 完成/重新打开任务型事件。

### 13.3 拖放与改期

- `【Web 对齐】` 通过 inspector 修改日期、开始时间和时长；重复任务提交前选择作用范围。
- `【macOS 增强】` 拖动事件可改变开始时间，拖动时显示吸附后的时间和冲突提示，默认 15 分钟粒度；Drop 前不提交，Drop 后进入 pending，失败回到原位置并显示原因。
- `【macOS 增强】` resize handle 在精确拖动稳定后再加入，不阻塞 Web 对齐验收。
- 重复任务必须选择作用范围。
- `【Web 对齐】` 已完成实例禁止直接改期，必须先通过可见操作重新打开，不静默更改完成记录。

### 13.4 时区

当前视图时区常驻 toolbar。切换只改变显示，不改写存储；编辑时明确显示任务原时区。DST ambiguous time 必须让用户选择 offset。

## 14. 笔记库

- Supplementary column：局部搜索、排序和笔记列表。
- 主侧边栏在进入笔记模块后展开项目、未归属和常用标签过滤。
- Detail 为只读预览；Return 或双击打开独立笔记窗口。
- `⌘N` 创建笔记，默认继承当前项目/标签过滤。
- Delete 移入回收语义由现有后端能力决定；首版没有回收站 API 时仍使用不可逆删除确认。
- `【macOS 增强】` 拖动笔记到项目建立关联；拖动文件到预览区转为附件。Web 对齐入口仍保留项目/任务选择器和“添加附件”按钮。

## 15. 笔记编辑器

### 15.1 原生与 Web 边界

原生 SwiftUI 负责窗口、标题、toolbar、菜单、inspector、附件、同步和保存状态；`WKWebView` 只承载 Tiptap 正文。

Bridge 事件：

- Native → Editor：加载 Markdown、设置只读、执行格式命令、插入附件链接、聚焦、查找；
- Editor → Native：正文变化、选择状态、字数、链接点击、假名操作、dirty 状态、保存请求和错误。

Bridge 消息必须带 note ID 与 editor generation，避免快速切换笔记时旧回调写入新文稿。

### 15.2 保存

- `【Web 对齐】` 每 5 秒检查变化并自动保存；`⌘S` 立即保存。后续如要调整为停止输入 800 ms 保存，应单独做负载和请求合并验证。
- 首版状态为“已保存”“正在保存”“保存失败”“离线只读”。不得在没有持久化队列时显示“离线草稿”。
- 窗口关闭时若保存仍在进行，等待短暂完成；失败则提示复制本地内容或取消关闭，不声称已经在后台排队。
- `【后端依赖】` Revision conflict 需要 note revision / CAS。接口完成后再增加比较 sheet，并提供保留远端、保存本地副本、复制本地内容三条路径。

### 15.3 编辑命令

- `⌘B` 粗体、`⌘I` 斜体、`⌘⇧X` 删除线；
- `⌘K` 固定为 FlowSpace 全局搜索；插入/编辑链接使用 `⌘⇧K`；
- `⌘F` 当前笔记查找；
- Format 菜单提供标题、列表、引用、代码块、分割线和假名标注；
- 选中文本时显示轻量 bubble menu，不遮挡当前行。

### 15.4 Inspector

分区为项目、关联任务、标签、同步、附件和文稿信息。同步目标改变后先保存绑定，再启用“同步此笔记”。解除绑定必须说明不会删除外部文稿。

## 16. 搜索

### 16.1 命令面板

`【Web 对齐】` 搜索任务、项目、日程和笔记，支持类型过滤与最近搜索。`【macOS 增强】` `⌘K` 从任何主窗口或笔记窗口打开命令面板，输入后 150–250 ms 防抖，并额外展示命令分组。

- ↑/↓ 选择，Return 打开，`⌘↩` 在新窗口打开；
- 搜索词为空时显示最近打开和常用命令；
- 输入 `>` 只搜索命令；
- Esc 关闭并恢复原焦点。

### 16.2 完整搜索窗口

`⌘⇧F` 打开完整搜索窗口，用于类型过滤、最近搜索和大量结果浏览。搜索选择不会改变其他工作区窗口的当前目的地，只有打开结果时才导航。

## 17. 快速捕获与菜单栏

### 17.1 快速捕获

`⌘⇧N` 打开单例窗口。`【Web 对齐】` 默认创建任务；笔记和日程类型属于 `【macOS 增强】`：

- 默认任务，保存到系统 inbox；
- 任务可设置项目、日期、时间块和优先级；
- 笔记可设置项目和标签；
- 日程必须设置日期，时间可选；
- `⌘↩` 保存，保存成功后清空并保持窗口打开；Option-`⌘↩` 保存并关闭。

关闭有输入的窗口需确认。服务离线时统一禁止提交；窗口可暂存当前输入并允许复制，但关闭后不承诺恢复，也不建立任务/笔记待提交队列。

### 17.2 MenuBarExtra

可在设置中开启，最多显示：

- 下一项任务，标题截断至 30 字符；
- 快速捕获；
- 打开今日；
- 当前同步/离线状态；
- 退出 FlowSpace。

复杂任务操作始终打开窗口，不把菜单栏变成缩小版工作区。

## 18. 内容导入

- Notes toolbar 和 File → Import 可发起播客导入；Window → Import Activity 打开导入任务窗口，不在主侧边栏增加固定入口。
- 创建 sheet 输入 URL、目标项目和整理要求；验证 URL 后立即创建后台任务并关闭 sheet。
- Import Activity 窗口展示来源、项目、当前阶段、进度、可重试状态和生成的笔记。
- 活跃任务轮询；窗口不活跃时降低频率。
- 可重试错误提供对应阶段重试，不从头重复已保存 artifact。
- `【Web 对齐】` 删除导入任务时明确说明已生成笔记会保留。`【macOS 增强】` 只有后端提供显式级联选项后，才允许用户选择同时删除笔记；默认始终保留。
- 任务完成时发送系统通知，点击通知打开生成笔记。

## 19. 每日总结

- `【Web 对齐】` 本周/本月范围位于 header，展示真实完成率、完成记录、仍需关注事项和最近笔记。
- `【macOS 增强】` 日范围与日期选择可在基础数据流稳定后增加。
- `【后端依赖】` 专注时间需要明确统计口径和接口，不以安排时长冒充实际专注时长。
- 单击条目打开原对象，Option-单击在新窗口打开。
- 数据为空时展示简洁说明，不用零值卡片填满页面。
- 总结是只读聚合，不在此处复制任务编辑表单。

## 20. 设置

使用独立 `Settings` scene，与总体方案统一为八类：

1. `【macOS 增强】` 通用：启动页、菜单栏、提示音、默认日历视图；
2. `【macOS 增强】` 连接：服务地址、测试连接、切换服务；
3. `【Web 对齐】` 个人资料：头像、显示名、语言、时区；
4. `【Web 对齐】` 账号安全：密码；会话管理后续扩展；
5. `【Web 对齐】` 同步：Notion/Obsidian 目标与默认行为；
6. `【Web 对齐】` 存储：数据库、对象存储和 binding 状态；
7. `【Web 对齐】` AI 服务：文本、转写、Codex 订阅；
8. `【macOS 增强】` 通知：任务、导入和同步通知。

切换服务地址属于高影响操作：先测试新连接，说明会退出当前会话并清空内存缓存，确认后切换。不得把旧服务的 Cookie 发送到新 host。

## 21. 账号管理

- 仅管理员通过用户菜单或 Window 菜单打开单例窗口。
- `【Web 对齐】` Table 列出用户、邮箱、角色、状态和是否需要改密；新建用户、重置临时密码和角色变更使用 sheet。
- 首版由管理员输入符合策略的临时密码，与现有 API 保持一致。
- 禁止管理员删除或禁用当前唯一管理员；错误必须来自服务端权威校验。
- `【后端依赖】` 若未来改为服务端生成一次性临时密码，再增加只显示一次和复制按钮；任何临时密码都不得写入日志或本地偏好。

## 22. 同步与附件

### 22.1 Notion / Obsidian

- 同步设置管理 target；笔记 inspector 管理单篇 binding。
- Push、pull 和冲突解决均显示明确方向。
- Pull 发现外部删除时进入待确认状态，不直接删除 FlowSpace 笔记。
- 同步中关闭窗口不取消服务端操作；结果通过 store 和通知回写所有窗口。

### 22.2 附件与音频

- `【Web 对齐】` “添加附件”选择文件后上传，成功后进入附件区，失败显示可重试错误。
- `【macOS 增强】` 文件拖入笔记编辑区先显示本地占位和上传进度；上传成功后写入正文引用或附件区，失败保留可重试占位。
- `【Web 对齐】` 音频转写展示上传、处理、完成和失败状态，并可把结果写入正文。
- `【macOS 增强】` 转写结果覆盖已有正文前增加预览或明确确认。

## 23. Mutation、冲突与撤销

### 23.1 通用 mutation 状态

1. 用户触发动作；
2. 客户端立即禁用重复命令并显示 pending；
3. 可安全乐观更新的轻量动作先更新 UI；
4. 服务端成功后合并 revision 并刷新相关 query；
5. 失败时回滚可见状态，保留选择与输入。

### 23.2 Revision conflict

- task-domain、Roadmap 和 runtime binding 的 409 不使用通用“操作失败”。
- 刷新当前对象并展示远端更新时间、变化字段和本地意图。
- 允许重放的命令由用户确认后使用新 revision 再执行。
- 文稿和 Roadmap 布局没有 revision API 时不伪造冲突处理；跨项目迁移不自动重放。

### 23.3 Undo

`【macOS 增强】` occurrence 完成后可在 8 秒内使用服务端返回的新 revision 发起重新打开。移动项目和归档只有在逆向命令、revision 及部分失败语义定义完成后才提供 Undo。删除账号、删除项目、删除笔记、取消有历史的任务不依赖 Undo，始终先确认。

### File

- New（`⌘N`）：根据当前模块创建项目、任务、日程或笔记；菜单标题随 FocusedValue 更新；
- Quick Capture（`⌘⇧N`）；
- Import Podcast；

### Edit

### View

- Today、Tasks、Inbox、Projects、Calendar、Notes、Daily Summary；

- Full Search（`⌘⇧F`）。

### Task

## 25. 加载、空、错误与离线

- 首次加载使用与真实行高一致的 skeleton；后台刷新保留旧内容，只显示轻量 activity。
- 空状态说明当前筛选或业务含义，并提供一个最相关动作。
- 网络错误保留现有内容和选择；页面顶部显示可重试状态，不用 modal 阻断整个 App。
- 401 统一回登录；403 保留页面并说明权限；404 清除已失效选择；409 进入冲突流程；5xx 提供重试。
- 离线只读时所有 mutation 控件统一禁用；网络中断前已经产生的未保存输入保留在当前窗口内存中，并提供复制或放弃，不能点击提交后才显示含糊失败。

## 26. 可访问性与输入方式

- 所有图标按钮有 accessibility label 和 help。
- 列表、Table、outline 和 canvas 提供 VoiceOver 顺序与 selected 状态。
- 颜色始终配合文字或图标表达状态。
- Increase Contrast 下减少透明度并增强分隔；Reduce Transparency 下使用系统不透明替代材质。
- Reduce Motion 下关闭 glass morph、列表移动和画布惯性动画。
- 最小点击目标遵循 macOS 控件尺寸；Inspector 使用 small/regular 控件，不压缩到不可读。
- 所有核心流程可只用键盘完成。

## 27. 验收场景

### 27.1 Web 对齐验收

1. 首次连接服务、登录并通过 v2 capability gate；非 v2 工作空间进入诊断页。
2. 快速捕获一个含项目、日期、时间块或重复规则的任务，在未整理中归入项目。
3. 在今日切换今天/本周/本月/已逾期/已完成，验证本周和本月按 task definition 折叠 occurrence，并完成、重新打开一个实例。
4. 在任务工作台切换固定视图，使用项目/优先级/状态/日期筛选，编辑 task definition 与 occurrence，并验证 task-domain revision conflict 不覆盖远端。
5. 创建和编辑项目，在项目详情查看概览、任务、日程、笔记、学习路线和历史；完成仍有未结束实例的项目时明确迁移或取消。
6. 生成 Roadmap，切换阶段 rail，打开节点脑图，新增/编辑任务并更新执行状态；不验收画布布局持久化。
7. 在周日历单击指定时间槽，验证日期和时间作为可编辑默认值；创建后再分别使用“仅本次”和“本次及以后”改期重复任务。
8. 新建笔记，验证 5 秒自动保存、任务关联、附件、日文假名和 Notion/Obsidian 同步；保存失败时不得显示“已保存”。
9. 发起播客导入，关闭创建 sheet 后任务继续，在 Import Activity 中查看阶段、错误、重试和生成笔记。
10. 搜索任务、项目、日程和笔记，验证类型过滤、最近搜索和结果导航；每日总结验证本周/本月、完成记录、待关注事项和最近笔记。
11. 修改个人资料和密码，检查数据库、对象存储、AI/转写、Codex 订阅和同步设置；管理员输入临时密码创建用户并管理角色与状态。
12. 明暗模式、Reduce Transparency、离线只读、401/403/404/409/5xx 和加载/空状态下完成回归。

### 27.2 macOS 增强验收

1. 任务列表使用键盘选择、contextual menu 和批量操作；批量部分失败必须逐项展示，不得显示全部成功。
2. 日历精确拖动使用 15 分钟吸附，失败回到原位置；resize handle 在独立功能开关和回归完成后验收。
3. 笔记多窗口、系统 Find、拖入附件、命令面板、快速捕获笔记/日程、MenuBarExtra 和通知分别验收，不与 Web 对齐通过条件互相阻塞。
4. 切换服务连接，确保旧 Cookie 和缓存不泄漏到新服务；窗口状态恢复不能恢复快速捕获、导入、设置或账号管理为启动窗口。

### 27.3 后端依赖转入条件

以下能力在对应 API 合同、迁移、服务端测试和 Web/macOS 跨客户端回归完成前，不得标记为已完成：

- 笔记 revision / CAS 与文稿冲突比较；
- Roadmap 原子重排与脑图布局持久化；
- 专注时间统计；
- 服务端生成且只展示一次的临时密码；
- 持久化离线草稿和增量提交队列。
