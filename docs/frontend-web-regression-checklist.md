# FlowSpace 前端网页回归测试清单

这份清单用于前端功能修改、依赖升级、样式调整和生产发布后的固定回归。测试人员按“操作”执行，界面必须满足“预期结果”；自动化列标为“是”的项目会由 Playwright 或 Vitest 在质量门禁中执行。

## 固定测试用户与数据

自动化测试使用纯前端拦截数据，不连接后端、不修改数据库：

- 用户：`网页回归用户`
- 邮箱：`web-regression@example.test`
- 角色：普通用户
- 工作区：`网页回归工作区`
- 任务模型：v2
- 项目：收件箱、个人事务、日语学习
- 示例任务：整理本周产品反馈，确认下一步改进计划
- 示例笔记：产品反馈记录

线上或标准测试机手工验收使用 `workspace_bootstrap_admin` 所属的现有测试账号。密码只保存在密码管理器或 CI Secret 中，不写入仓库。开始前确认工作区为 `model_version=v2`、`migration_state=cutover`、`accept_legacy_writes=0`。

涉及新建、修改、完成、归档或删除的数据统一使用前缀 `WEB-REG-日期-`，只删除本轮测试创建的数据，不操作真实业务数据。

## 每次更新的执行规则

在 `frontend/` 目录运行：

```bash
npm run test:regression
```

该命令依次执行前端 Lint、全部单元测试、生产构建和桌面 Chrome、Android Chrome、iPhone WebKit 浏览器回归。首次运行前安装浏览器：

```bash
npx playwright install chromium webkit
```

GitHub `Quality gates` 已在每次生产分支更新和涉及 `frontend/**` 的拉取请求中运行相同检查。任何一步失败都不得继续发布。浏览器失败时下载 `frontend-playwright-report`，查看截图和 trace。

建议执行层级：

- P0：每次提交或合并必须运行自动化回归。
- P1：每次生产发布后，在真实登录会话中手工执行标为“发布后”的用例。
- P2：导航、布局或响应式样式有变化时，完整执行本清单。
